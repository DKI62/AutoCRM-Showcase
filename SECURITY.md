# Безопасность

[К проекту](README.md)

Сообщайте об уязвимостях приватно через GitHub или напрямую сопровождающему проекта. Используйте тестовые данные, не прикладывайте токены и реальные записи.

Showcase отключает сетевой Telegram и Expo OTA. Серверные тесты используют синтетические данные. Резервные копии не шифруются; храните их и ключи вне Git.

## Известные уязвимости

Три записи High из `npm audit` относятся к одной цепочке: `expo-router@57.0.31` → `query-string@7.1.3` → `decode-uri-component@0.2.2` ([CVE-2026-118664](https://github.com/advisories/GHSA-qr28-fpjm-wq7f), [CVE-2026-45822](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr)). Некорректный ввод может нарушить доступность приложения.

Showcase ограничивает длину входящих ссылок и отклоняет некорректное кодирование. Серверный бандл Worker не включает эту цепочку. Уязвимости остаются неисправленными: прямое обновление декодера несовместимо с текущим CommonJS-вызовом. Требуется отдельно проверенное обновление Expo Router или перенос исправления.

# Серверный протокол

[К проекту](../README.md)

Обработчики Cloudflare Worker используют привязку D1 для хранения состояния устройств, версий задач и ожидающих действий. Новая привязка требует подтверждения на устройстве. Изменения задач передаются с версиями, а обработка действий подтверждается отдельно.

Showcase не отправляет запросы к серверу из приложения. В автоматических проверках Worker получает синтетические запросы, SQLite временно подменяет D1, а тестовый транспорт имитирует ответы Telegram.

## Локальные проверки

Запустите `npm test` из корня репозитория. Тесты охватывают подтверждение привязки, обмен задачами, подтверждения действий и запланированные напоминания.

Для ручной проверки маршрута здоровья установите Wrangler и выполните команды ниже из корня репозитория. Пример использует локальную D1 и тестовые параметры.

```powershell
Copy-Item server/telegram/.dev.vars.example server/telegram/.dev.vars
wrangler d1 migrations apply DB --local --config server/telegram/wrangler.example.jsonc
wrangler dev --local --config server/telegram/wrangler.example.jsonc --ip 127.0.0.1
```

В отдельном окне выполните `Invoke-RestMethod http://127.0.0.1:8787/health`. Отправку сообщений проверяют автоматические тесты с подключённым имитационным транспортом. Локальный экземпляр Wrangler такой транспорт не подключает.

# Сборка Android и демонстрационные данные

[К проекту](../README.md)

## Подготовка

Установите Node.js 24 с npm, JDK 17, Android Studio и Android SDK с Platform Tools и Build-Tools. Используйте PowerShell 7.2 или новее. Windows PowerShell 5.1 разбирает синтаксис скрипта сборки, но при строгой обработке ошибок останавливается на выводе `java -version` в stderr. Подготовьте эмулятор или подключите устройство Android с разрешённой USB-отладкой. Проверьте версию командой `java -version` и доступность устройства командой `adb devices`. Укажите JDK 17 в `JAVA_HOME`, а путь к SDK — в `ANDROID_HOME`, если SDK установлен вне стандартной папки.

При первом запуске нужны интернет, установленные зависимости и загрузка компонентов Gradle. Команды предполагают, что вы открыли корень репозитория.

## Сборка для разработки

```powershell
npm ci
$env:APP_VARIANT = 'development'
npm run android
# Для последующих запусков Metro
npm start
```

Эта сборка использует пакет `com.autocrm.showcase.dev`. Expo Go не включает модуль `AutoCrmAlarmAccess`, который проверяет доступ к точным будильникам Android и открывает настройки.

## Автономный APK

Для автономного варианта используйте отдельную рабочую копию без сгенерированной папки `android` от сборки для разработки. Скрипт проверяет пакет `com.autocrm.showcase`, конфигурацию подписи демонстрационной сборки и манифест APK.

```powershell
npm ci
pwsh -NoProfile -File demo/build-samsung.ps1
pwsh -NoProfile -File demo/pack-sample.ps1
```

Первый скрипт записывает APK в `.cache/samsung/auto-crm-showcase.apk`, второй создаёт `.cache/samsung/auto-crm-showcase-data.zip`. Автономное приложение работает без Metro.

## Импорт примера

1. Перенесите APK и ZIP на устройство Android. Установите приложение **Auto CRM Showcase**.
2. Распакуйте ZIP в отдельную папку. В приложении откройте **Настройки → Контроль и хранение → Восстановить из папки**.
3. Выберите папку с `manifest.json` и `media` и подтвердите импорт. В примере пять автомобилей, четыре задачи, история и демонстрационная фотография. Повторный импорт пропускает карточки с уже известными идентификаторами.

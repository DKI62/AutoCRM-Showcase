# Отдельная установка на Samsung

## Готовые файлы

В локальной папке `.cache/samsung` демо-архив содержит `manifest.json` и `media`. Это пять вымышленных карточек, четыре задачи, история и одно синтетическое изображение. Команда `pwsh -File demo/pack-sample.ps1` создаёт демоархив с задачами на актуальные даты.

## Установка отдельной APK

Пакет автономной сборки — `com.autocrm.showcase`, название — **Auto CRM Showcase**. У рабочего приложения, рабочего Dev Client и Showcase DEV отдельные пакеты. Showcase использует свою SQLite и отдельный ключ SecureStore. OTA и сетевой Telegram отключены.

На сборочном компьютере нужны JDK 17, Android SDK с Build-Tools и Node.js. В отдельном checkout Showcase выполните:

```powershell
npm ci
pwsh -File demo/build-samsung.ps1
pwsh -File demo/pack-sample.ps1
```

Скрипт собирает локально подписанный APK для демонстрации и проверяет package ID в его манифесте. Выходной файл — `.cache/samsung/auto-crm-showcase.apk`. Скопируйте его и `.cache/samsung/auto-crm-showcase-data.zip` на Samsung. Установите APK через «Мои файлы», затем убедитесь, что открыт именно **Auto CRM Showcase**. После установки Metro и рабочий сервер для этого APK не требуются.

Если в checkout уже сгенерирован Android для другого варианта, используйте свежий checkout Showcase. Скрипт останавливается при несовпадении пакета или профиля подписи. Подпись локальной сборки предназначена для демонстрационной установки и хранится отдельно от рабочих credentials.

## Импорт

Распакуйте ZIP через «Мои файлы» в отдельную папку Downloads. В **Auto CRM Showcase** откройте **Настройки → Контроль и хранение → Восстановить из папки**. Выберите папку, непосредственно содержащую `manifest.json` и `media`, подтвердите импорт пяти карточек. Все характеристики, записи истории и задачи в этом архиве вымышленные. Фотография находится у **Demo Silver Sedan**. Используйте только этот синтетический архив.

## Если локального SDK нет

Для облачной APK используйте отдельный проект EAS. Профиль для съёмки собирает Android APK командой Gradle `:app:assembleRelease` с демоподписью из шаблона Expo. Проверьте бесплатную квоту перед сборкой. Для распространения за пределами собственной тестовой установки потребуется собственный ключ Showcase. Рабочие проекты и ключи в этой процедуре не используются. После получения APK следуйте инструкциям установки и импорта выше.

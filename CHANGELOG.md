# Changelog

## 1.0.0 · portfolio snapshot

- Android vehicle CRM with offline records, tasks, media, local reminders, appearance settings and folder backups.
- Includes the revisioned synchronization protocol, pairing v2 and controlled retry and acknowledgement handling.
- Showcase uses separate Android identifiers, synthetic backup generation and a local Telegram fixture. Live delivery and Expo OTA are disabled.

This snapshot is intended for source review and local demonstration.

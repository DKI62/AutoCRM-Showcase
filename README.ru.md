# Auto CRM

**Автономная Android CRM для работы с автомобилями.** Независимая разработка под задачи заказчика. Showcase содержит код приложения и обезличенную серверную реализацию.

[English](README.md) · [Инженерный кейс](docs/CASE-STUDY.md) · [План съёмки](docs/screenshots/README.md)

## Возможности

- Карточки автомобилей, цены и характеристики, фото и вложения, заметки и история.
- Задачи, повторения, поиск, фильтры, стадии и архив.
- Локальные Android-уведомления, экспорт и импорт резервной копии, светлая и тёмная темы.

## Архитектура

Expo Router вызывает репозиторий, который сохраняет данные и очередь в SQLite. Фото хранятся в закрытом каталоге приложения. Синхронизация в рабочей редакции обменивается версиями задач и подтверждениями действий с Cloudflare Worker и D1. Pairing v2 требует подтверждения на телефоне. В Showcase доставка моделируется в тестах, отправка реальных сообщений отключена. [Диаграмма](README.md#stack-and-architecture) · [Руководство по серверу](docs/SERVER.md)

## Запуск

Нужны Node.js 22, npm, JDK, Android SDK и отдельный эмулятор. Установите зависимости командой `npm ci`. В PowerShell задайте `$env:APP_VARIANT = 'development'` и выполните `npm run android`. Для повторного запуска Metro используйте `npm start`.

Проверки запускаются командами `npm run typecheck`, `npm run lint`, `npm test` и `npx expo-doctor`. В демо можно [импортировать синтетические записи](docs/screenshots/README.md). Галерею заполняют реальные снимки отдельной установки.

Исходники представлены для ознакомления с портфолио. Открытая лицензия на код проекта не предоставлена. Сторонние зависимости распространяются на собственных условиях.
